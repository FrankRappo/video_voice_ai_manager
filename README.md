# Video Voice AI Manager

Транскрипция голосовых и анализ видео через существующие бэкенды Gemini,
Whisper и OpenAI. Для голосовых из Telegram используется команда `voice`.

## Запускать в фоне

По указанию владельца от 04.11.2026 длительные файловые задания всегда
запускаются через фоновый контроллер:

```bash
cd /work/video_voice_ai_manager
python3 run_background.py voice /work/tg/files/example_voice.ogg
```

Команда сразу возвращает PID, каталог задания, лог и путь результата.
Повторный запуск совпадающего активного задания возвращает его существующий
PID. Ждать завершения и опрашивать статус циклом без явной просьбы не нужно.

- [Правила для агентов](AGENTS.md)
- [Команды фонового запуска и проверки статуса](BACKGROUND.md)
- [История использования](USAGE_NOTES_2026-05-28.md)
- [Обработка видео](video-processing.md)

Ключи хранятся в существующей конфигурации `vvam.json` или переменных окружения.
Исходные записи, результаты, временные файлы и конфигурация с ключами
исключены из Git.
