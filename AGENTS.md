# VVAM — правила работы

## Указание владельца от 04.11.2026: запускать обработку в фоне

- Транскрипцию голосовых, анализ видео и другие длительные файловые задания
  запускать **всегда в фоне**. Каноническая команда — `python3 run_background.py ...`.
- После запуска проверить создание задания и сохранить PID, время старта,
  пути входных файлов, логов и результата. Вернуть управление пользователю.
  Не держать диалог открытым ради ожидания и не опрашивать статус циклом.
- Дождаться завершения можно только по прямому указанию владельца. Однократная
  проверка статуса допустима по его запросу или при разборе готового результата.
- Уже запущенные процессы сохранять: перед повторным запуском проверить их
  фактическое состояние и наличие результата. Не создавать дубликаты.
- Ошибка, пустой файл или один запущенный процесс не доказывают успешную
  расшифровку. Проверить результат и указать, какие исходные файлы обработаны.
- Результаты и временные файлы хранить внутри проекта, а не в `/tmp`.
  Голосовые, видео, расшифровки, логи, конфигурация с ключами и кеши в Git
  не добавлять. Исходники пользователя без его указания не удалять.
- Не задавать ограничения времени, простоя, RAM или swap, обрывающие активную
  обработку. Очистка временных файлов следует за фактическим выходом процесса.

## Среда выполнения

Владелец явно разрешил транскрипцию через Gemini в WSL для этого фреймворка.
Это исключение относится к обработке речи; правила VPS для приложений других
проектов сохраняются. Остановка другого задания или агента не отменяется
запуском транскрипции.

Подробности и примеры: [BACKGROUND.md](BACKGROUND.md).
